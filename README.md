# TRAZA clínica

Prototipo de investigación del estado documental clínico mediante grafos, procedencia y tiempo. Sólo datos sintéticos; no utilizar para decisiones asistenciales.

## Inicialización del repositorio

Este primer commit crea la referencia Git de un repositorio previamente vacío, por solicitud de Felipe del 14 de octubre de 2026. No publica una versión estable ni modifica una aplicación desplegada.

La incorporación de TRAZA v0.3.0 y la base de gobernanza se preparan en una rama de tarea para revisión hacia `develop`. `main` queda reservada para promociones revisadas desde esa rama de integración. No se ha realizado un merge ni una aprobación automática.

La constitución de referencia es «Constitución de Código Agéntico v1.0». Su copia íntegra, el mapeo local de autoridades y las validaciones se incorporarán en el PR de configuración inicial.
