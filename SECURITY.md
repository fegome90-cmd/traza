# Seguridad y divulgación responsable

**Estado:** prototipo de investigación con datos sintéticos. No ingreses datos clínicos reales, credenciales ni identificadores personales en issues, PRs o demos.

Para vulnerabilidades: utiliza el canal privado **Security → Report a vulnerability** del repositorio si está habilitado o contacta de forma privada al titular `@fegome90-cmd`; **no publiques un exploit ni datos sensibles en un issue abierto**. No se garantiza respuesta bajo SLA.

Dependencias y fuentes externas se consideran no confiables. No ejecutar comandos remotos copiados sin revisión. No agregar servicios, puertos, tokens, permisos o integración de terceros sin evaluar riesgo y obtener autorización apropiada.
